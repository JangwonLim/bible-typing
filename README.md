# 말씀 타자 대결

교회에서 1:1로 성경 말씀 한 구절을 누가 더 빠르고 정확하게 치는지 겨루는 타자 페이지입니다.

## 사용법

1. 두 노트북에서 같은 주소를 열고, 같은 말씀과 같은 벌점을 고릅니다.
2. 입력칸을 누르고 첫 글자를 치면 시간이 시작됩니다.
3. 끝까지 똑같이 치면 자동으로 끝나고, 오타가 있으면 `Enter`로 제출합니다.
4. 최종 기록이 짧은 사람이 이깁니다.

**최종 기록 = 걸린 시간 + (남은 오타 + 지운 횟수) × 벌점**

- 치는 도중 `Backspace`/`Delete`로 지운 횟수도 벌점에 들어갑니다.
- 붙여넣기는 막혀 있습니다. `Esc`를 누르면 처음부터 다시 시작합니다.
- 말씀 본문은 개역한글입니다. 다른 번역본은 "직접 입력하기"로 넣을 수 있습니다.

별도 설치 없이 `index.html` 파일 하나로 동작합니다.
