# 말씀 오락실

교회에서 1:1로 성경 말씀 한 구절을 누가 더 빠르고 정확하게 치는지 겨루는 오락실 스타일 타자 게임입니다.

**주소:** https://jangwonlim.github.io/bible-typing/

## 하는 법

1. 두 노트북에서 같은 주소를 열고, 같은 말씀과 같은 벌점을 고릅니다.
   - `←` `→` 분류 바꾸기(짧은 · 보통 · 긴 · 성령의 열매 · 직접 입력), `↑` `↓` 말씀 고르기
   - 마우스로 말씀을 한 번 누르면 선택, 한 번 더 누르면 시작
2. `Enter`를 누르면 3-2-1 카운트다운 뒤에 말씀이 열리고 시간이 시작됩니다.
3. 말씀 위에 바로 칩니다. 끝까지 똑같이 치면 자동으로 끝나고, 오타가 있으면 끝까지 친 뒤 `Enter`로 제출합니다.
4. 결과 화면의 **FINAL** 기록이 짧은 사람이 이깁니다.

**FINAL = 걸린 시간 + (남은 오타 + 지운 횟수) × 벌점**

- 치는 도중 `Backspace`/`Delete`로 지운 횟수도 벌점에 들어갑니다.
- 등급: S 실수 없이 300타 이상 · A 실수 3% 이하, 220타 이상 · B 실수 8% 이하, 140타 이상 · 그 밖은 C
- 플레이 중 `Esc`는 처음부터 다시, 결과 화면의 `Esc`는 말씀 고르기로 돌아갑니다.
- 붙여넣기는 막혀 있습니다. 음악과 효과음은 시작 화면에서 끌 수 있습니다.
- 말씀 본문은 개역한글입니다. 다른 번역본은 "직접 입력"으로 넣을 수 있습니다.

## 팀전 릴레이

시작 화면의 **팀전 릴레이** 탭에서 합니다. 팀마다 노트북 한 대를 씁니다.

1. 인원을 정합니다 (기본 8명, 2~20명, `↑` `↓` 또는 ◀ ▶).
2. **대결 코드** 4자리를 두 노트북에 똑같이 넣습니다. 같은 코드면 같은 말씀 9개(짧은 3 · 보통 3 · 긴 3, 순서 랜덤)와 같은 교대 위치가 나옵니다. `새로 뽑기`로 다른 판을 만들 수 있습니다.
3. 1번 주자부터 칩니다. 치는 도중 사이렌과 함께 **교대!**가 뜨면 1.5초 동안 입력이 잠기고, 그 사이 다음 주자가 이어서 칩니다. 교대는 띄어쓰기 직후에만 걸립니다.
4. 말씀 하나가 끝나면 바로 다음 말씀으로 넘어갑니다. 팀 전체 시간이 계속 흐르고 30초마다 경고음이 울립니다.
5. 9개를 다 치면 팀의 FINAL 기록이 나옵니다. 계산은 개인전과 같습니다.
